## Implemented Features
- **Insert line (Core):** Inserts text at a specified line index.
- **Delete line (Core):** Deletes a specific line by index.
- **Display document (Core):** Prints all lines with numbers.
- **Save / Load (Core):** Reads from and writes to `.txt` files.
- **Search (Bonus):** Case-insensitive word/phrase search across lines.
- **Find & Replace (Bonus):** In-place string replacement across the document.

## How to Compile & Run
```bash
gcc -Wall -Wextra editor.c -o editor
./editor
